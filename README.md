# Stock Portfolio Tracker

A simple Python project to track stock investments. This is Task 2 for my Python Internship.

### Features
- User can input stock names and quantities
- Uses a hardcoded dictionary for stock prices
- Calculates total investment value
- Saves the portfolio report to a .txt file

### Tech Stack
- Python
- Dictionary, Input/Output, File Handling

2. Run the script
